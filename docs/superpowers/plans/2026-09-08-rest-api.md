# REST API for Generation & Regeneration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add REST endpoints (FastAPI) for course-outline generation and all three regeneration scopes, reusing the existing pipeline in-process, while the CLI keeps working exactly as today.

**Architecture:** Extract the CLI's orchestration into a shared `outline/service.py` (both CLI and API call it). An in-memory async **job registry** (`outline/jobs.py`) runs each request as a background task — POST returns `202 {run_id}` immediately; GET endpoints report status and serve the run folder's artifacts. Run folders stay the single source of persistence (`run_id` = folder name), so a restarted server still serves completed runs. No DB, no queue, no auth (MVP; noted as future work).

**Tech Stack:** FastAPI, uvicorn, httpx (tests), existing `outline/` package (graph, regen, prompt_guard, report), FakeLLM for offline tests.

**Spec:** `docs/DESIGN-Course-Outline-Generator-LangGraph.md` (pipeline contracts) + `docs/BUILD-GUIDE-Course-Outline-Generator.md` §H3 (API surface shape) + this plan's endpoint table.

## Global Constraints

- CLI behaviour unchanged: `python -m outline generate|regenerate …` flags, outputs, exit codes identical (refactor may move code, not semantics).
- Endpoints (v1):
  - `POST /v1/outline/generate` — body = the existing input JSON + optional `provider`, `model`, `batch_size` → `202 {"run_id", "status":"queued"}`
  - `POST /v1/outline/regenerate` — body `{"baseline_run_id" | "baseline_dir", "unit": "all"|"N"|name, "lesson"?: "M"|name, "prompt"?: str, "provider"?, "model"?}` → `202 {"run_id"}`
  - `GET /v1/outline/runs` — list run folders (id, n_los, provider, started_at, status)
  - `GET /v1/outline/runs/{run_id}` — `{"status": "queued"|"running"|"done"|"failed", "detail"?, "report"?}` (report summary when done)
  - `GET /v1/outline/runs/{run_id}/outline` | `/report` | `/analysis` | `/regeneration` — the artifact files (404 if absent)
  - `GET /healthz` → `{"ok": true}`
- Prompt-guard rejection → HTTP **400** with the guard's user-facing message (never a 500, never a queued job).
- Unknown baseline / bad unit/lesson selection → **404/422** with the same messages the CLI prints.
- Job failure (provider auth, PipelineBug) → status `failed` with the error string; run folder may be absent.
- `run_id` == run-folder name (`<ts>_<N>LOs_<course>_<provider>`); path traversal must be impossible (`run_id` validated against `^[A-Za-z0-9._-]+$` and resolved strictly under `runs/`).
- All tests offline via `"provider": "fake"`; suite must stay green (`pytest -q`, currently 83 passed 1 skipped).
- New deps land in a `[project.optional-dependencies] api = ["fastapi>=0.115", "uvicorn[standard]>=0.30", "httpx>=0.27"]` extra; core install unaffected.
- Code formatted with black; commit after every task; never `git add -A`.

# tests/unit/test_jobs.py
import asyncio
from pathlib import Path
from outline.jobs import JobRegistry


async def test_job_success_and_failure(tmp_path):
    reg = JobRegistry()

    async def ok():
        return (tmp_path / "r1", {"n_los": 1})

    async def boom():
        raise RuntimeError("provider exploded")

    jid = reg.submit("r1", ok())
    jid2 = reg.submit("r2", boom())
    for _ in range(50):
        await asyncio.sleep(0.01)
        if reg.status(jid)["status"] == "done" and reg.status(jid2)["status"] == "failed":
            break
    assert reg.status(jid) == {"status": "done", "run_dir": str(tmp_path / "r1")}
    assert reg.status(jid2)["status"] == "failed" and "exploded" in reg.status(jid2)["error"]


def test_resolve_unknown_job_falls_back_to_folder(tmp_path):
    reg = JobRegistry()
    (tmp_path / "old-run").mkdir()
    (tmp_path / "old-run" / "report.json").write_text("{}", encoding="utf-8")
    assert reg.resolve("old-run", tmp_path)["status"] == "done"
    assert reg.resolve("nope", tmp_path)["status"] == "unknown"

import time
from fastapi.testclient import TestClient
from outline.api import app

client = TestClient(app)


def _wait_done(run_id, timeout=30):
    for _ in range(timeout * 10):
        r = client.get(f"/v1/outline/runs/{run_id}").json()
        if r["status"] in ("done", "failed"):
            return r
        time.sleep(0.1)
    raise AssertionError("job did not finish")


def test_generate_and_fetch_outline(input43, tmp_path, monkeypatch):
    monkeypatch.setenv("OUTLINE_RUNS_DIR", str(tmp_path))
    r = client.post("/v1/outline/generate", json={**input43, "provider": "fake"})
    assert r.status_code == 202
    run_id = r.json()["run_id"]
    status = _wait_done(run_id)
    assert status["status"] == "done" and status["report"]["validation"] == []
    outline = client.get(f"/v1/outline/runs/{run_id}/outline")
    assert outline.status_code == 200 and outline.json()["label"] == "project"
